## 🔑 Key Features

### **Sales Performance Analysis**
- Total revenue, total orders, average order value  
- Category-level revenue (Clothing, Accessories, Footwear, etc.)  
- Revenue by U.S. location  
- Discounted vs. non-discounted revenue  

### **Customer Insights**
- Unique customer count, average customer age, repeat purchase rate  
- Customer age segmentation (18–25, 26–35, 36–45, 46–55, 56–65, 66+)  
- Revenue by gender  
- Payment method breakdown  
- Seasonal purchasing patterns  

---

## 🛠 Technical Highlights
- Built using **Power BI Desktop**  
- **Power Query** for cleaning, transformations, and shaping data  
- **Star-schema model**:  
  - FactSales  
  - DimCustomer  
  - DimProduct  
  - DimBehavior  
- Custom **DAX measures** for KPIs:  
  - Total Revenue  
  - Total Orders  
  - Average Order Value  
  - Repeat Purchase Rate  
- Page-level and report-level slicers for dynamic analysis  

---

## 🎯 Purpose of the Dashboard
This dashboard was designed to mirror real business reporting standards:

- Clear KPI summaries  
- Segmentation and behavior insights  
- Standardized metrics for leadership & regulatory review  
- Intuitive structure similar to:  
  - Credit risk teams  
  - Portfolio monitoring  
  - Finance and operations reporting  
  - Executive dashboards  

The focus is on **clarity, accuracy, and repeatable logic**.

## 🚀 How to Use
1. Download the `.pbix` file

3. Interact with filters and slicers  
4. Explore sales patterns and customer behavior
